# Prompts de imagens para a Home do Imóvel Prático

## 1. Hero / Software Enterprise
Crie uma imagem 16:9 premium para uma landing page de SaaS imobiliário chamado Imóvel Prático. Visual de software enterprise, dashboard moderno em tela grande, tons azul petróleo, grafite, dourado elegante e off-white. Sensação de empresa grande, produto caro e confiável. Elementos sutis de mapas urbanos, dados, propriedades e cards de análise. Sem textos legíveis na imagem, apenas interface fictícia sofisticada.

## 2. Captação Imobiliária Inteligente
Crie uma composição visual 16:9 premium mostrando o conceito de captação imobiliária inteligente: mapa urbano abstrato, prédios elegantes, pontos de dados conectados, painel digital e fluxo de informações. Estilo sofisticado, corporativo, tecnológico, tons navy, azul petróleo, dourado e branco quente. Sem pessoas identificáveis, sem marcas reais, sem textos legíveis.

## 3. Processo Automatizado
Crie uma imagem horizontal 16:9 premium representando um fluxo automatizado: endereço → índice cadastral → proprietário → contato → exportação. Use cards flutuantes, linhas luminosas, interface SaaS minimalista e visual de alta tecnologia. Paleta azul petróleo, grafite, dourado suave e off-white. Sem textos legíveis.

## 4. ROI / Valor percebido
Crie uma imagem 16:9 para seção de ROI de uma landing page premium. Mostrar dashboard executivo, gráficos ascendentes, economia de tempo, operação organizada e ambiente corporativo imobiliário. Visual elegante, luxuoso e limpo. Sem textos legíveis.
